## 本地交付范围

- 随程序提供 Java21、Python3.11、独立 YOLO/PyTorch 环境、FFmpeg 和已校验模型种子。原生运行不需要 Docker、MySQL 或开发环境 PATH。云同步仍为可选。
- 用户目录保存 SQLite、模型、课程素材、缓存和诊断；笔记包含文字、图片与可编辑标注。API Key 使用 Windows DPAPI 加密，备份不夹带密钥或原视频。
- 自动管理本程序后台，具备就绪检测、端口冲突处理、崩溃/退出清理与随机本地访问凭证。数据维护具有互斥和恢复日志；升级前一致性备份，旧版本程序保留供恢复。
- 模型下载提供固定来源、大小和 SHA256 校验、断点续传、取消及磁盘检查。设置提供运行设备、模型准备、API 配置、备份恢复、缓存和脱敏诊断。
- 自动模式优先使用可用 GPU，按模块回退 CPU；严格 GPU 模式不能满足时明确失败。

## 本次补修

1. CPU 冷启动导入可能超过原45秒探测预算。CPU每项探测改为90秒，整体仍受300秒启动上限约束。
2. 启动失败清理后曾把错误状态覆盖成“已停止”。现在保留明确失败原因，便于设置界面重试和诊断。
3. 本题答疑：完整回复的 JSON、必需字段或引用校验失败后，在原请求上下文追加原回复与纠错要求，最多修复一次。原课程材料、图片、历史和课程优先讲解策略保留；不接受虚构引用。HTTP错误、截断回复和过长回复不触发这次格式纠错。只记录脱敏原因/次数/用量，不记录回复正文。

真实复测确认模型首次用了本题允许范围外的引用ID，第二次修复后通过；没有修改导图生成、粗选或同页分组算法。
