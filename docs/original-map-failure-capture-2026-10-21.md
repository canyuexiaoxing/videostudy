# 原方式导图：本地失败现场与无损格式修复

完成时间：2026-10-21 10:08（上海时间）。沿用整课一次生成、原输入、现有节点与展示方式；未启用分批方案。

## 改动

1. 原方式的 JSON/结构解析失败、输出被长度等结束标记中断，以及修复回复改变原内容被拒绝时，单独保存本地失败文件，关联任务编号、请求编号、阶段、结束标记与错误位置。原失败和失败的纠错回复拥有各自的请求编号。
2. 文件位于 `数据目录/logs/private-model-failures/*.json`；桌面默认数据目录为 `%APPDATA%/Framewise/data`。开发运行位于 `.local/logs/private-model-failures`。
3. 这些文件含本地课程回复，仅供本机排错；不写普通事件日志，不进入“导出诊断”和课程备份，不自动上传。过滤当前请求密钥、环境密钥、Bearer 凭据、常见 sk 密钥与 data:image 内容。脱敏文件不参与生成、恢复或无损比较；错误位置以未脱敏原回复为基准。
4. 每份最多 4 MiB，最多 12 份，总量不超过 32 MiB。新失败留存时清理超过 7 天的旧文件并按限额淘汰；超限整份跳过，不保存截断正文。磁盘或权限错误不遮蔽原模型错误。`MODEL_FAILURE_CAPTURE=0` 可关闭留存。
5. 纠错提示区分“尾随分隔符”“多余闭合括号”“第二个 JSON 对象”“文字或其他内容”，提供原文位置和长度，提示中不复制课程片段。第一次整课请求的内容、预算及图片不变，仍最多一次模型纠错。
6. 修复保留校验新增一种可证明安全的情形：完整根对象之后，仅剩少量空白、逗号或多余右括号。只在比较时恢复原内容树；真实修复回复仍须严格解析。尾部如果还有文字、另一个不同对象、新数组或疑似课程字段，不允许丢掉。节点顺序、层级、公式、引用及原有内容的检查保留。
