## 结论与限制

本次最大的耗时是 OCR（約占总执行时间 77%），其次是与它并行的语音转写。继续提高页面 API 并发不会减少这 400 秒 OCR。批量提图已缩短了提图步骤，但不改变每张 OCR 的识别工作。

容器每秒采样的最高内存约 3416 MiB（3.34 GiB）。这是采样值，可能漏掉瞬间峰值，且包含文件缓存等容器计费内存，不只是模型内存。

本次是单次真实样本测试，时间受 CPU、磁盘、模型初次加载和 API 延迟影响。此前约 16 分 21 秒的运行使用过不同补采数量和处理逻辑，不是严格对照，不能把差值都归因于并发优化。
