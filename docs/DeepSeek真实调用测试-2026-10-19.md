# DeepSeek 真实调用测试（2026-10-19）

用户明确授权调用收费 DeepSeek API。本轮使用当前已配置的 `deepseek-flash`，通过软件真实 Java API → Python agent → DeepSeek 测试，所有返回均来自真实模型；未替换模型回复。没有重跑用户历史课程。

## 范围与消耗

- 累计实际 HTTP 请求 **20 次**，全部 HTTP 200、finish_reason=stop；这不代表业务全部成功。
- 输入 70,851 tokens，输出 10,186 tokens，合计 **81,037 tokens**。其中输入缓存命中 37,888、未命中 32,963。没有推算人民币费用。
- 模型 HTTP 等待累计 **61.52 秒**，不是整个测试的墙钟耗时；容器准备、数据库读写、轮询、排错另计。
- 五组短合成课程：增长量/增长率、二次函数、3-4-5 直角三角形、直流串联电路、光合作用；前四组提供真实 JPEG 测试图片。不是长课压力测试，也不覆盖视频转写、OCR、YOLO 的运行质量。
- 使用独立 SQLite、图片目录和临时容器。模型 Key 仅从现有容器环境读取，不输出、不写报告；不记录完整模型请求/回复或图片 base64。测试结束移除临时容器，保留测试资料与应用数据库供复核。

## 质量与交付判断

七次出题调用各请求 3 题，最终通过校验并保存 **9 题**；其中两次几何请求连 JSON 都未解析成功。校验拦截不可当成出题成功。对已保存题目抽查：函数对称轴、f(3)=9、(2,4) 是否在图上；串联电流相等；光合作用原料/能量/场所；增长率 32/160=20%，答案与测试材料一致。此抽查不能证明任意课程的正确率。

成功保存的 9 题 `diagram` 均为空，函数与电路题含 LaTeX 文本。虽然出题和问答确实收到了课件图，但**本轮没有生成通过校验的新函数图/几何图/电路图**，不能宣布新结构图生成已验证通过。

HTTP 服务可用，但出题/问答输出格式仍有不稳定，当前不宜声称各场景均通过交付验收。下一步应针对非法 LaTeX 转义、结构图引用、同会话出题证据关联，补充失败样例与格式纠错；不应放宽证据、算式或电路结构检查来凑成功率。本次未修改导图生成、选图或同页分组算法，也未给模型生成增加自动重试。

## 已修复的问题

SQLite 重复插入异常在 Spring 中被包装为 UncategorizedSQLException，旧的 DuplicateKeyException 捕获仅兼容 MySQL，导致已有解读/章节再次请求报 500。两个控制器改用现有 DatabaseDialect.duplicate 判断，仅复用确定的重复记录；其他数据库故障继续抛出。增加 task/request/stage/result/elapsedMs 日志。

新增真实 SQLite 回归测试，先复现失败，再修复通过；独立 HTTP 测试确认复用时没有额外付费调用。最终 Java 测试结果：**145 项，0 失败、0 错误、0 跳过**。
