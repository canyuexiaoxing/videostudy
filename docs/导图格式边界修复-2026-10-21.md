# 导图 JSON 格式边界修复 · 2026-10-21

本次仅修改格式规范、格式纠错提示及诊断，不修改导图节点组织、公式与例题取舍、层级生成、证据材料或显示逻辑。严格解析与内容保留检查保持原样。

## 改动

- 首次请求补充根对象闭合检查：必需字段全部位于同一个根对象内，子节点闭合不等于整课对象闭合，结束后不得追加字段、逗号、括号、说明或另一个对象。公式字符串中的括号按字符串处理。
- 自动纠错遇到 syntax_trailing_content 时，补充完整回复长度、首个非法尾部字符位置，以及能够独立解码时的首个根对象结束位置。位置由程序计算，不让模型自行猜测。
- 同一会话仍只允许一次纠错，保留原始课程材料和完整错误回复。明确禁止仅截取合法前缀、丢弃后半段或移动节点；不确定能否无损修复时仍拒绝发布。
- 自动纠错后再次出错时，单独记录第二份回复的错误类型、位置及回复长度。日志不保存课程正文、完整模型回复或密钥。
- 更新格式提示版本标识，区分此次请求与旧格式缓存。输入材料、请求预算和超时不变。
