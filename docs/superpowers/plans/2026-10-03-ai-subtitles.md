# AI 字幕实现计划

> 依据已确认中英字幕规则，当前对话内直接执行。分工并行，最终由主代理检查接口、测试、部署和实测；本次不自动提交 Git。

1. **Python 校准模块与测试**：保留来源 ID/时间，50 条左右分段提供同页 OCR 与上下文；变化列表协议、有界重试、近音及实际增删过滤、理由和依据校验。验证中文近音、英文近音、添语气词、语义改写、伪造时间/依据、四种语言方向和失败回退。
2. **Java 独立任务**：新增数据库迁移、来源/目标语言任务存储、内部授权回调、独立执行器、公共查询/生成接口。保持现有接口重载兼容；验证来源触发后主流程继续、关闭生成、删除和晚到结果、队列与重启、失败隔离。
3. **Python 流程接入**：同页分组后发布异步文字来源，固定回调地址、随机课程令牌、自动传输重试；新增 `/subtitles` 路由。验证接入点和无阻塞，不重新做 OCR、不读取图片。
4. **前端**：高级生成开关及目标语言，独立轮询和原始/AI 切换，修改对照，原始资料不被覆盖；任务切换/删除/卸载清理轮询，切换不改变播放位置。验证状态和 WebVTT 安全。
5. **集成与部署**：GPU 镜像增加模块及轻量拼音依赖，更新本地服务、迁移数据库；完整 Python/Java/前端回归、实际 API 中英小样和已有真实课程字幕测试，浏览器确认字幕开关与回放。记录结果和质量限制，不把模型推断当成确定事实。
