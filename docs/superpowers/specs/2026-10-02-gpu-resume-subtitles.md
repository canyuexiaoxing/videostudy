# OCR GPU、导图并行、阶段恢复与同步字幕

## 目的

保留现有识别与证据规则，提高课程完整分析速度。用户选择的优化范围为 OCR GPU、导图分块并行、失败步骤复用；同时要求同步字幕及完整课程耗时测试。

## 约定

- GPU 只用于 PP-OCRv6 medium；Whisper base 保持 CPU/int8。提供可选 GPU Compose 配置，CPU 部署仍可使用。
- 导图最多 3 个分块请求同时运行，汇总顺序和依据时间按原课程保留。每次 provider 请求仍最多 3 次尝试。
- 成功的转写、视觉证据、补采检查、分组、页面和导图分块保存在本任务截图目录的 `.analysis` 中，原子写入。失败结果不复用。输入、模式、阈值、模型、提示版本或任务媒体身份改变后不复用旧结果。
- 完整分析可自动恢复一次（首次加一次恢复，共两次），只重算未成功的步骤；HTTP 永久客户端错误不重试。成功写入 MySQL 后删除临时视频和恢复缓存，保留当前产品需要的截图。失败保留临时视频与恢复证据最多 24 小时。删除任务时删除整个任务截图目录及缓存。
- 字幕使用转写 startMs/endMs 生成 WebVTT，在 HTML 播放器上叠加；支持开关、跳转和全屏，不修改原视频、不额外调用模型。
- 完整实测使用原 29 分 28.853 秒样本，包含本地 HTTP 上传、Java 排队、真实模型处理、结果保存与读取；明确本地上传不代表公网传输速度。记录各阶段、任务完成状态和显存/内存采样，未成功不称为完整成功。

## 验证

测试覆盖并行顺序、成功结果恢复/失效、失败结果排除、字幕时间与转义、有限自动恢复、存储删除。实际 GPU OCR 用已有截图作对照，真实课程仅按已授权的完整测试运行；失败由程序恢复，不手工重放模型请求。
