# 遮挡处理、同页整理与内容版本保护方案

状态：设计草案，尚未实施。2026-10-17。

## 1. 目标与决定

先解决“同页入口太碎”和“代表图漏掉独有内容”，再追求减少模型输入图片。

- 保持现有72%同页判断和原始 `pageGroups` 不变，新增整理层，不全局降至65%。
- 区分三个概念：原始截图、原始分组、展示用同页集合。一个同页集合允许包含多个真实内容版本。
- 同页集合只有一个课件入口；给模型的图片可以是一张，也可以是几张必要的互补图。
- 最后一张没有优先权：被遮挡或模糊时，不得仅因更晚就替换清晰旧图。
- 不删除原图、不拼接板书、不改造原图时间；不改变导图层级和例题归并规则。
- 首版不新增模型调用、不重跑OCR/YOLO、不重新解码视频、不自动处理历史课程。

## 2. 已有证据及限制

本地报告：`.local/qa/grouping-multi-20261017/综合结论.md`、`.local/qa/representative-dedup-20261017/结论.md`。

- 65%可减少幂级数视频的碎组，但增长量的新旧记录都出现“红笔与黑笔两套讲解合组，只选了旧图”的真实漏选；旧记录70%也有风险。
- 代表图间保守去重额外约0.09～0.24秒，但每份记录仅少1张；宽松版曾误删最终和函数及收敛域提示图，不能推广。
- 初次声称“65%遗漏08:10”已撤回：它在另一个新组仍保留。后续质量评价必须追踪整课最终入选图，不能只按旧组号比较。
- 样本为3门不同视频、4份任务；重复任务不算独立课程。历史图片时间精度未在本轮重验，未测云模型耗时及生成后导图质量。
- 当前YOLO只在粗选使用，人物掩码没有作为分组结果持久保存。不能假设分组阶段已知道哪些位置被遮挡。

## 3. 首版流程

```text
原有粗选、OCR、覆盖检查和补采（保持原样）
  → 原72%分组（保留全部原组）
  → 相邻组代表图关系检查
  → 构建同页集合、登记内容版本和不确定区域
  → 必要时读取相关组已有截图作局部复核
  → 生成课件展示入口、必要图片清单和来源映射
  → 经验证后接入整课直生成；不新增模型调用
```

第一阶段只生成整理结果和离线报告，不改变模型输入。通过验收后才接课件展示；模型图片调整单独验收。

### 3.1 判断同页关系，不判断数学语义

只从时间相邻的原组生成候选，综合：题干或多块正文在相同位置持续存在、主体布局、局部笔画、有效区域和文字冲突。标题、背景相同或时间接近都不足以证明同页；同主题不等于同题。

关系枚举：

| relation | 含义 | 行为 |
|---|---|---|
| `duplicate` | 可确认是相同内容 | 可归入同页，继续选图检查 |
| `extension` | 页面主体保留，局部内容新增 | 同页，登记后续版本 |
| `revision` | 同页出现替换、擦除或纠正 | 同页保留前后版本 |
| `new_page` | 主体内容被替换、题干不同或真实换页 | 新集合 |
| `uncertain` | 遮挡、OCR波动或画面不足 | 保持原入口，不强行合并 |

连续讲6分多钟也可能同页，不设“超过几十秒必拆”的规则。反过来，不能仅凭A像B、B像C就认定A与C内容等价。所有合并需保留直接来源依据。

72%、65%以及97%像素覆盖都不是知识完整率；现有实验阈值仅可用于候选排序，不可直接作为正式删图准入条件。

### 3.2 内容版本与可见性分开登记

每个内容版本维护真实截图时间和以下局部状态：`visible`（当前可观察）、`occluded`（有可靠遮挡依据）、`changed`（可确认内容发生变化）、`unknown`（不可判定）。

- OCR识别不到文字，不等于该位置没有内容；出现人体外形，也不能证明被挡区域内容没有变化。
- 高置信OCR中的数字、运算符、否定和条件发生冲突时，登记变化或不确定，不能按相似图去掉。
- 图片中的图表、细小上下标和未识别公式也可能重要；没有OCR覆盖的位置，禁止默认为空白或已覆盖。
- 没有可靠人物遮罩时，允许保持 `unknown`。首版不自动给非YOLO任务开启YOLO；后续若复用粗选掩码，必须有真实时间戳、尺寸及模型版本校验，不能按邻帧猜掩码。

### 3.3 代表图选择

顺序是：内容覆盖与版本保护 → 清晰、遮挡较少 → 时间先后作同质量时的末位排序。OCR字数不再作为“内容更完整”的充分证明。

| 输入情况 | 必须得到的结果 |
|---|---|
| 后图完整保留旧内容并新增公式 | 可选后图，但须核对已替代的所有原图 |
| 后图遮挡旧内容，没有可靠新增 | 保住前面清晰图；证据不足可两张都留 |
| 后图有新内容，同时挡住旧内容 | 保留前后互补图 |
| 后续出现一张无遮挡完整图 | 仅在直接覆盖各旧版本后再替换 |
| 旧推导擦除后出现新方法、纠正或最终答案 | 前后版本都保留，不把“更密集的旧推导”当作新答案的替代 |
| 红笔、黑笔两套批注 | 独立检查，不能只选OCR最丰富的一套 |
| 来源损坏、区域错位、画面移动或判断不清 | 不裁减，保留原资料并说明不确定 |

只减少模型入选图，不物理删除源文件。不能强制每页最多一张或两张；如果必要图片过多，保留证据并让裁减失败，不能为了限额丢内容。

### 3.4 按需复核与补采

首版局部复核只读取已经完成OCR的组内原图：每个待判关系最多额外读2张、整课最多16张。优先读取现存的较晚且清晰画面。这是I/O上限，不是保留图片数量上限。

达到上限仍不确定时，保留原代表图和未解决状态，不再递归、不补跑OCR，不把未确定候选从资料中移除。

现有覆盖补采先于最终分组。首版不得在分组后重新运行它而增加模型请求。后续若联动：需在现有覆盖检查开始前，利用增量OCR产生待核对区域，加入同一覆盖检查输入，共享原轮次和次数上限；这是第二阶段，不包含在首版落地范围。

## 4. 数据契约与兼容

新增可选字段 `pageCollections`，不覆盖 `pageGroups`：

- `collectionId`：按本次输入指纹和原组序列稳定生成，不作图片sourceId。
- `sourcePageIndices`：有序原组编号；只能引用本课程存在且连续的原组。
- `firstFrameTimeMs` / `lastFrameTimeMs`、`memberFrameTimesMs`：由原组和真实截图计算，不由模型生成。
- `versions`：各项含 `versionId`、`frameTimesMs`、`relation`、`visibility`、`reasonCodes`。
- `representativeFrameTimesMs`：最终必要真实图片，至少一张；任何替换都保留旧图到新图的直接映射。
- `unresolvedFrameTimesMs`：不能安全替代的资料，不得静默丢弃。
- `status`：`completed`、`uncertain`、`fallback`；状态不是数学完整性保证。
- `policyVersion`、`inputFingerprint`：用于缓存、补采变化后的失效和历史兼容。

`frame_<实际毫秒>`仍是原图证据ID；版本ID、集合ID和展示序号不能作为图片引用。缺文件或时间越界时不猜时间、不用邻图替代。

旧记录没有字段就沿用原组；新版异常或预算超限就整批回退原组和原图，不发布已经裁掉一半的结果。Java的 `TranscriptResult`、兼容构造器、`withMindMap`、笔记更新及持久化往返必须保留新增字段，不能依赖未知JSON字段自动透传。

## 5. 接入边界

- 前端：一个同页集合一个课件入口，内部显示“完整画面 / 其他讲解画面 / 待核对”等简单提示；仍可查看全部原截图与真实回看时间。展示合并不意味着物理删除或模型只看一张。
- 整课直生成：由单独适配器构建模型用页面列表，合并原成员、选入必要版本，保留 `sourcePageIndices`。原 `pageGroups` 不变；不得让新代表图挂到一个不包含它的旧组。引用注册表、时间、图像hash及保存的导图上下文同步更新。
- 分组后汇总：首版只新增课件展示元数据，原增量分组分析、候选ID和模型请求保持不变；不宣称已减少该模式的逐组请求。后续优化需另外验证跨页衔接和候选来源。
- 旧练习、字幕、章节仍消费原 `pageGroups`，不在首版重编号；导图语义结构、原格式/引用最多一次修正额度保持原样。

## 6. 时间、资源与失败处理

正式默认关闭；用开发配置 `PAGE_COLLECTIONS=off|observe|apply` 分阶段接入。`off`不运行新步骤；`observe`仅产出元数据、不改变模型图片；`apply`只能在验收后由明确配置启用。

试验目标而非性能保证：现有最多109张截图、35组样本上，代表图检查新增p95不超过0.5秒；包含有限组内复核时全步骤不超过1.5秒。特征缓存最多32MiB；只读小图和OCR位置，按需淘汰，不缓存整段视频高清帧。

预算超限、取消、源图变化均停止裁减。取消随原任务传播，不得被吞成普通回退；文件/OCR/区域/分组/策略变化使缓存失效。普通整理错误回退原资料，不能使已成功的转写或原导图入口失效。

不新增模型调用不等于端到端必然更快。先测本地时间和必要图片量；新增必要图片可能增加模型输入，必须披露。未做真实调用时不估算云端提速百分比。

日志沿用白名单、轮转和隐私限制：任务ID、阶段、策略版本、输入组数、集合数、选图数、回退原因、耗时。不得记录课程正文、OCR原文、原图或密钥。

## 7. 验收与上线条件

至少覆盖：幂级数35组数据、增长量新旧记录、极限题及当时真实区域配置。后两份增长量记录作为重复控制，不当作独立视频。

必查真实画面：08:10完整推导在整课仍入选；红/黑笔两套讲解都能找回；23:06推导与24:12最终和函数/收敛域提示均保留；18:32/18:48删改不会误丢独有内容。

合成反例：末帧遮挡、遮挡同时新增、模糊、数字/正负号纠正、小上下标、无OCR图形、共同模板不同题干、区域移动、擦除重写以及非传递替换。人工标注重要区域/公式片段作为质量依据，不用OCR保留率或像素覆盖率替代质量结论。

准入要求：已标注关键内容新增遗漏为0；误合并不同题干为0；全部原引用仍可追溯；不新增模型请求；满足本地预算；全部取消/重试/历史往返测试通过。若只减少入口、不减少图片，按实际结果报告，不包装成提速。
