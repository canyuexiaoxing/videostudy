# 页面解析格式兼容

## 需求与实现

模型返回格式出现局部偏差时保留可用解析。标题和正文必须是非空字符串，顶层必须是对象；这些核心字段不可用时保留原有格式重试及失败处理。

辅助说明字段接受字符串、字符串列表和结构明确的对象。修正对象按 original、correction、basis/reason 转为说明；推导按 claim、basis/reason 转为说明；通用条目接受 text/content/description/point。不猜测陌生字段含义，也不直接把任意对象转成字符串。

辅助字段缺失或部分条目无法理解时，以空集合或过滤后的集合供后续流程使用，将缺失与过滤情况写入 uncertainties。主要正文保留，页面标记 unverified，不把缺失判断当成确认无问题。缺少 confirmedContent 时不把正文自动填入已确认内容；缺少遮挡判断时不据此触发补图。

所有接收入口统一归一化：模型 HTTP 响应、文字路线、图片路线、补图和计算复核。已有计算矛盾仍执行原来的有限复核；格式兼容不验证语义真伪。页面版本升为 v6，使后续重新分析不复用旧版页面缓存。

## 验证与缓存

测试覆盖结构对象转换、非核心缺失不重试且保留正文、无法识别辅助条目提示、核心缺失仍重试或失败。用历史留存的三次本课模型响应离线验证兼容性。

部署不自动修改数据库已有的 failed 页面，也不自动调用模型或重算字幕。旧课程结果需要明确重新解析或使用留存响应恢复，不能仅靠点击字幕生成就获得未保存的成功解析。
