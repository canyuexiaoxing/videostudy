# 视频工作台：忽略区域后端接入（2026-10-10）

用户确认前端工作台后，授权接入后端。入口为课程视频标题右侧“视频工作台”，第一项工具为“忽略区域”。

## 任务配置与接口

- 前端按文件指纹保存一个矩形，提交新分析时通过 multipart `ignoredRegion` 传 JSON `{x,y,width,height}`；坐标相对于视频画面，比例范围为 0～1，画面外的黑边不参与框选。
- Java 在落盘、创建任务前验证字段、数值、边界和面积；非法设置返回 400 `invalid_ignored_region`。面积超过95%拒绝。省略字段保持原流程。
- V11 增加 `transcription_jobs.ignored_region_json`，旧任务为 NULL。失败重试和自动恢复调用沿用该任务保存的区域，浏览器重新框选仅影响新任务。
- Python 接口使用同样的校验，worker 每次绑定媒体时重置区域，分析缓存上下文包含区域，避免不同配置混用结果。

## 算法作用范围

1. 粗选：FFmpeg 同时输出320×180灰度预览和同几何变换的有效像素掩码，兼容横屏、竖屏及视频旋转。忽略区域与预览产生的黑边不计入变化比例分母。相邻变化和30秒累计变化检查使用同一掩码。采样间隔仍支持2/3/4秒，末帧保留逻辑不变。
2. 同页分组：在画面差异、位移对齐、空白判断和代表图清晰度比较时排除区域。用于分组的OCR副本过滤至少50%包围框面积落在忽略区域内的文字块；缺少可靠坐标时保留。原始OCR块索引保留，引用仍可核验。
3. 原始证据：正式截图不涂黑、不裁切，OCR仍识别完整截图，`visualEvidence`原始记录不改写。覆盖审查和补采保持完整截图；忽略区域不承诺删除所有涉及摄像头的证据或阻止覆盖审查补采。

## 使用

选择视频 → 打开视频工作台 → 暂停到摄像头可见画面 → 开始框选 → 确认区域 → 关闭工作台 → 开始分析。仅支持一个固定区域；视频内摄像头移动位置时需要适当框大或重新设置。

代码复核发现并修复NULL区域任务新增缓存字段导致旧检查点失效的问题：仅非空区域加入缓存上下文。增加旧版上下文实际缓存文件回归测试，确认无框选旧任务可复用转写阶段，避免重复调用已完成模型阶段。
