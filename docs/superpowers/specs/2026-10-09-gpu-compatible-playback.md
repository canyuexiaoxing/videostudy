# 显卡兼容播放

## 需求
本机 Edge 100 对 HEVC 原视频返回 DECODER_ERROR_NOT_SUPPORTED，Chrome 154 可播放；8 秒 H.264 对照样片在两者均可播放。
用户批准加入按钮，使用显卡生成兼容副本。字幕纠错暂停，不增加 AI 请求。

## 实现
视频标题旁“显卡兼容播放”，分析前即可使用。检测后台 NVENC 能力后上传原文件，显示上传和转码两个进度。
Java 保存临时上传并调用 Python；Python 一次只接受一个转码任务，FFmpeg CUDA 解码、h264_nvenc 编码，yuv420p，原 AAC 直接复制，其他音频转 AAC。
不自动回退 CPU。GPU/驱动/编码失败显示错误，保留原视频播放和分析结果。
输出 MP4 使用 faststart；不裁剪、不变速、不指定新帧率，核对输出时长误差不超过 250ms。
完成后切换播放地址，保留位置、暂停状态、音量和倍速；可切回原视频并复用副本。
Java FileSystemResource 提供分段 Range 请求，供章节、字幕、导图跳转。

## 临时数据
存于 MEDIA_TEMP_DIR/compatibility/<UUID>，源文件转换结束立即删除；失败移除不完整副本。
切换文件、取消、卸载页面时请求删除任务及副本。异常关闭兜底清理过期目录，阈值 24 小时。
UUID 严格验证，不允许用户自定义文件路径。目录属于临时播放会话，不进入分析历史。

## 部署与验证
GPU Docker 设置 NVIDIA_DRIVER_CAPABILITIES=compute,utility,video，保留现有 gpus:all。
宿主 FFmpeg 9 的 NVENC 13.1 与本机驱动 NVENC 13.0 不匹配，因此按钮使用容器 FFmpeg，必须实测其编码成功。
验证 GPU 编码、不采用 CPU、时长一致、Range 播放、取消/删除和前端构建。
容量说明仅针对单任务，不承诺具体整课转码耗时；待真实样片统计。

## 本机验证结果
- RTX 4060 Laptop，容器 NVENC 能力检测通过，宿主 FFmpeg 9 的驱动接口不匹配未用于按钮。
- 原视频一分钟 HEVC 截段经实际上传、GPU 转码和状态轮询：5.327 秒；输出 H.264＋AAC，60.033 秒，2,900,808 字节。该结果不代表远程上传或整段视频耗时。
- 视频资源 Range 请求返回 206、Content-Range 和正确的 1024 字节响应。
- Edge 100：原视频错误码 4，点击按钮后 readyState=4，定位 20 秒后正常播放。
- Chrome 154：切换保留 12 秒位置和暂停状态；兼容副本可定位、播放、切回原视频。
- 两浏览器测试均无 JS 异常、无课程分析 POST 请求。
- 真实取消任务后临时目录已删除；测试副本均已清理。
- Python 147 项测试通过（跳过 1），Java package 检查通过，前端类型检查与构建通过。
