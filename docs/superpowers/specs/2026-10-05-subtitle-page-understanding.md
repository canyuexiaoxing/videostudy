# 字幕校正使用页面理解

用户点击生成后，字幕输入包含原始语音、附近上下文、同页 OCR，以及已有的图片理解或文字理解结果。仍采用单轮决策，不重新识图、不额外复查。

Python 按原有时间窗口选择页面，白名单传入解析的状态、标题、内容、图表说明和不确定项。失败结果不传入；推导或未核实内容保留状态提示，不能当成确定事实。解析文字不能伪装成 OCR 引用，修改理由说明使用了哪页上下文，引用字段仍仅接受真实 OCR。

Java 在手动请求时，用保存的最终课程结果刷新旧的字幕来源快照，让历史课程也能使用已有解析。校正版本升级至 v8；旧字幕标记可更新，用户点击后才重新调用模型。

离线验证覆盖：无 OCR 的已解析页面仍提供上下文、文字路线兼容、失败解析排除、图片路径及私有字段过滤、历史来源刷新、字幕格式和时间保留。不能由这些测试推断实际纠错率提高，仍需真实课程对比评测。
