# AI 时间章节与播放器

用户要求按视频时间划分章节，独立于知识导图；移入播放器显示分段时间条，悬停显示章节名称与时间。2026-10-04 调整：点击进度条定位到点击处的实际时间，不吸附章节开头；章节目录仍回到对应章节开头。

AI 读取按时间排序的原始转写及少量页面标题线索，返回章节标题和起始转写 ID。程序从原始片段换算时间，拒绝未知 ID、重复/倒序边界，覆盖开头至最后一条转写。视频实际尾部由播放器最后一章延伸至本地媒体时长。每章结束等于下一章开头；章节不是按固定分钟切分，也不复用导图树。

结果独立存 MySQL 并级联删除。主任务保存后异步排队生成；旧任务读取时可以自动请求，已完成结果复用。失败不影响导图、字幕及播放，网络/格式错误有限重试。章节语义边界仍需抽查，不把生成完成等同于分段准确。

Vue 播放器沿用 HTML video 和本地文件，隐藏原生控件，提供播放暂停、时间、分段定位、静音音量、倍速、全屏、章节目录。鼠标离开隐藏浮层，键盘焦点及暂停时保持可用；触屏可点击唤出。字幕原生轨道保留，播放器整体全屏包含自定义控制栏。验证跳转、悬停、边界比例、未知时长、课程切换隔离及字幕兼容。

## 实现与验证（2026-10-03）

- Python `chapters.py` 生成独立章节；Java 章节任务表与工作线程保存、复用结果；Vue `ChapterPlayer.vue` 呈现分段播放器。删除分析记录时章节结果级联删除。
- 时间条各段宽度按真实时长分配。点击或拖动均定位到对应实际时间。悬停显示章名、起止范围和鼠标对应时间；目录提供完整章节列表。
- 已完成的约 29 分钟课程复用 608 段转写与页面线索，真实 API 生成 16 章，生成请求记录耗时 2.276 秒。这只是章节生成耗时，不是上传或完整分析耗时。
- Chrome 实测悬停标题、点击第二章跳至 108.1 秒、目录跳转、播放、移出隐藏控件、移入显示控件及播放器整体全屏；原文/AI 字幕切换保留本地文件和播放位置，无浏览器运行异常。
- Python GPU 测试 128 项、Java 测试 40 项通过；前端构建通过，18 项前端测试通过。实际播放器复查包含现有字幕兼容。

章节数量不是准确率指标。部分标题仍可能继承原始转写的同音误字；程序约束时间来自真实语音片段，但章节语义及切分点仍需多课程评测。
