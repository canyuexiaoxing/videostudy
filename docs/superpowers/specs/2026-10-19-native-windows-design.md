# Framewise Windows 本地交付设计

用户授权：一次完成本地安装所需功能、GPU优先、无Docker、全面测试记录时间；除必要授权不再中途确认。沿用已有设计意图，自主完成设计和实现，不反复请求批准。

## 验收范围
Windows 10/11 x64；桌面端随带Java运行环境、独立Python与YOLO隔离环境、FFmpeg；运行环境不依赖开发目录、PATH、Docker、MySQL。GPU按模块真实试运行，自动模式优先GPU、不支持则CPU并解释原因；严格GPU模式失败清晰提示。

本地数据存用户目录 data/{database,models,uploads,keyframes,logs,cache,backups,runtime}；API Key由Windows DPAPI加密，renderer只收到hasKey。主进程管理原生后端启动、就绪检测、崩溃状态和退出清理；仅终止自己拥有的进程；端口占用另择端口，不连接陌生服务。数据目录/网络代理/错误提示不暴露密钥。运行仅绑定127.0.0.1，随机访问令牌保护本地API；浏览器开发模式保持兼容。

模型目录与程序分离；清单固定路径、大小、SHA256、可信HTTPS源；断点续传、超时取消、校验、磁盘空间、损坏重下；无服务器发布源时提供随包离线模型，不伪造可用下载链接。

设置窗口提供模型准备、API配置、运行设备、后台状态、目录、备份恢复和脱敏诊断。备份/恢复需后台停止或一致性快照，保留笔记和SQLite，不拷贝原视频、不外泄密钥；仅允许清理明确可再生缓存。升级保留数据、SQLite升级前备份、失败可恢复旧程序，卸载默认保留数据。

出题空结果可重新生成，区分失败/少题/空题；不改导图和已有模型算法。已有云同步保留为可选，不随本地启动而启动云容器。

## 可验证性
单元故障测试覆盖下载中断/校验失败/磁盘不足、路径逃逸、无GPU/驱动错误/OOM、后台超时/崩溃/端口占用、加密不可用、备份损坏/回滚、空题重试。原生环境真GPU/CPU、小视频分析、真实模型API、退出重开/数据恢复、离线启动、本地端口冲突、安装/卸载/升级演练。

未实测的其他显卡、全新物理电脑、代码签名/SmartScreen信誉不冒充通过。记录依赖许可证、模型授权、版本锁定与所有缺口。
