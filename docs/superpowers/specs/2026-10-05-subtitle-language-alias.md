# 同语言字幕选项共用结果

“保持原语言（仅校正）”和已识别的原语言是同一功能。中文视频选择中文应复用中文校正；英文视频选择英文应复用英文校正。只有选择不同语言才生成翻译。

Java 服务根据已保存的字幕来源语言（或课程结果语言）统一查询和生成键。已有 `source` 记录优先；旧课程只有显式语言记录时直接复用它。两份旧结果都存在时固定返回 `source`，不按修改数量推断质量。已完成的旧结果不重算或覆盖。

原语言尚未识别时可先创建等待来源任务；识别后重复的待执行同语言任务被取消，避免重复付费请求。已经执行中的旧任务不强行中止，但展示始终统一。跨语言翻译不合并。

回归覆盖同语言查询与生成复用、旧显式语言缓存、旧重复缓存、识别前重复排队、英文语言码及跨语言隔离。
