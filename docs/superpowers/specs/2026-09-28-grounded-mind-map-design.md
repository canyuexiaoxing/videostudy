# 可回溯课程思维导图设计

> 后续视觉与层级要求见 `2026-09-28-mind-map-canvas-redesign.md`；下文保留首版规格记录。

> 状态：本轮实现规格。依据：`docs/系统设计方案.md` 的 R-02、R-03、6.3；用户要求点击导图内容直接跳转原视频。采用项目现有的规格驱动开发流程，规格、接口、测试相互对应。

## 目标与范围

完成全量分析的任务返回真实课程思维导图，结构为课程根节点、章节主题、知识点。知识点由 Agent 从转写提炼，必须关联已有转写片段；画面页面作为章节上下文，不能让模型杜撰视频时间。点击任意有依据节点时，桌面端跳到本地视频/音频的对应位置、播放并高亮转写原句。无本地文件时显示重新选择提示，导图和引用仍可阅读。旧任务无导图时继续显示转写和 PPT 结果，并可点击按钮使用保存的转写补生成导图；此操作无需原视频，也不重做 ASR/OCR。

本轮不实现学生答题、错因诊断、跨课导图合并或手工编辑。不能将“接口演示”的固定节点冒充真实导图。

## 数据契约

`TranscriptResult.mindMap` 为可选对象，旧 JSON 缺失时是 `null`。新对象包含 `status`（`completed` / `empty` / `failed`）、`provider`、`modelId`、`promptVersion`、`createdAt`、`root`。根、章节、知识点统一使用节点结构：`id`、`title`、`startMs`、`endMs`、`evidenceRefs`、`children`。证据结构为 `sourceType`（首版为 `transcript`）、`sourceId`（`TranscriptSegment.id`）、`startMs`、`endMs`、`quote`。所有时间以媒体起点后的毫秒表示；`startMs`、`endMs` 从已存转写读取，不接受模型生成的时间。

知识点至少一个有效证据；无有效引用的模型输出被丢弃。章节时间取第一个有效子节点的时间，根节点取第一章节的时间。没有可用转写时返回 `empty`，界面明确说明原因，不生成凭空知识点。模型请求按有界转写块分批，避免一小时视频一次性请求造成不稳定；块内最多 80 段，模型每块最多给出 6 个知识点。模型提供章节主题、知识点标题及引用片段 ID；程序负责引用、去重、时间和树形结构校验。

## 交互与异常

完成分析后导图显示在转写稿上方。节点按钮显示主题和时间，点击时显示引用原句、设置播放器 `currentTime = startMs / 1000` 并尝试播放；转写稿中对应段落高亮并滚动到可见位置。用户拒绝自动播放时仍完成跳转并提示手动播放。关闭应用后重新打开旧任务且未重新选择本地文件时，点击节点提示重新选择文件；后端不恢复已删除的视频。

Agent 请求失败或全数输出无有效引用时，`mindMap.status=failed`，其他已完成的转写与页面分析仍可保存；界面说明导图未生成，不伪装成空课程。部分块失败时保留已验证节点并标记 `failed`；用户可继续点击有依据节点，并可手动重试导图生成。

旧任务补生成使用 `POST /api/transcriptions/{id}/mind-map`：仅接受已完成任务；已有完整导图时直接返回原结果，缺失或部分失败时由 Java 发送已存的转写与页面标题到 Python 内部 `/mind-map`，生成后更新该任务的 `result_json`，其余分析字段保持不变。失败时返回错误且保留原始任务结果。前端只在旧任务或部分失败任务显示按钮，防止读取历史结果时自动付费调用模型。

## 验收

- R-03a：给定两段不同时间的转写，生成至少两个有证据知识点；点击各点跳转不同时间。
- R-03b：模型引用不存在的片段 ID 或自造时间不会进入结果；证据原文来自真实转写。
- R-03c：音频文件复用相同跳转；无视频轨道但有转写时仍有导图。
- R-03d：无转写时明确返回 `empty`；模型异常时返回 `failed` 且不丢失已完成分析。
- R-03e：旧结果缺少 `mindMap` 时 Java 能反序列化，桌面端仍可读取。
- R-03f：Vue 构建、Java 契约测试、Python 生成与引用校验测试通过。
- R-03g：现有已完成任务可由按钮补生成并持久化导图，刷新后仍可读取；不重新上传视频。
