# 字幕单轮校正

## 用户要求与行为

大模型结合相邻语音文字和同页 OCR，在一次请求中决定是否修改字幕。有充分依据就直接采用；不确定则不返回修改，保留原文。不请求第二次语义复核，不以标准拼音或英文音码否决短语纠错。

仍要求保留原句结构，尽量对齐读音，最小修改；不得无依据扩写或增加语气词，迫不得已最多增删一个字或词。这些是提示词指导，由模型判断，不再由程序逐字否决。模型只能看到转写和 OCR 文字，不能宣称听过原音。

## 实现与边界

- 每块最多 50 段字幕，加相邻只读上下文和关联页面 OCR；正常每块只有一次模型请求。
- 修改包含片段编号、文本、具体理由以及实际使用的精确 OCR 引用；仅用上下文作依据时引用数组为空。
- 程序保留编号范围、唯一性、非空文本与理由、OCR 时间与原文引用检查；翻译保留目标语言检查。
- 原始字幕独立保留。校正只改文字，不改编号、顺序、时间。
- 临时网络错误或无效 JSON 最多尝试三次；这是请求失败重试，不是语义复查。不确定或空修改不会重试。
- 提示词版本更新为 `subtitle-calibration-v4-single-pass`；旧缓存不自动重算。

## 验证

用模拟返回验证有 OCR 依据的“限期期 → 减基期”直接采用、仅请求一次、不确定时原文保留；继续验证伪造引用、越界编号、重复编号、时间保护及失败回退。这些检查证明流程策略，不证明真实模型纠错准确率。

本设计替代 2026-10-03 方案中的近音硬性过滤与集中语义复核。历史实测仍保留其当时的版本与调用数，不作为本版本耗时依据。
