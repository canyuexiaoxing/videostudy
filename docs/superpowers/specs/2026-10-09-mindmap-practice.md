# 导图知识点练习

用户已确认：基于导图知识点出题，模型决定是否配图，图题需校验；关联某次解析，保存题目和答题记录；点击选项立即判分、显示解析，不需要提交按钮。

## 范围
- 解析完成且导图有课程依据后，用户选整图或节点分支，智能数量或 3/5/10 道、基础/应用/综合难度。
- 第一版提供单选、判断，均可一次点选完成；不提供需要多次选择后提交的多选题。
- DeepSeek 接收所选节点快照、节点关联原句及相关页面理解；不得把练习假设数据冒充视频原文。
- 图按结构化数据绘制，支持柱状/折线/表格和限定拓扑的串并联电路；不接受模型任意 SVG 或复杂图像。
- 检查必需字段、证据来源、选项唯一、数值计算、图数据与特定拓扑。无法校验的配图或答案不合格，整题舍弃；不无限修复、不为凑数量发新请求。
- 语义真实性不是仅靠结构校验就能保证，界面保留课程依据与回看入口。

## 数据
practice_sets 关联 transcription_jobs；保存导图版本哈希、选定节点/证据快照、生成参数、私有答案、解析、结构化配图及校验结果。
配图由数据渲染，无独立位图文件，因此随题库清理，不产生孤立图片。
practice_sessions / practice_answers 保存匿名浏览器练习会话和点选记录，未来可加 user_id。无登录时不承诺账户隔离。
外键级联，删除解析记录同时删除题库、图数据、会话和答题记录。
重新生成导图不改旧题的节点快照。读取缓存不重新调用模型。

## 接口与交互
GET/POST /api/transcriptions/{analysisId}/practice；生成异步，轮询状态。
POST /practice/{setId}/sessions 创建新练习；GET 恢复会话；POST /sessions/{sessionId}/answers 点选答题。
未答题的响应不含答案/解析/计算检查。已答题仅对当前浏览器会话返回反馈。
重复点击和重复请求不得产生不同答案或重复计分；答题失败保留可重试，不能假装保存成功。
切换课程停止旧轮询和旧答题结果覆盖，题库无内容时显示原因，不自动请求。

## 验证
Python 构造正确/错误计算、未知来源、错误图、重复选项输入。
Java H2 验证保存、匿名会话、答案隐藏、幂等点选、跨解析拒绝、导图快照和级联删除。
前端构建及浏览器真实接口验证选择后反馈、刷新恢复、图查看和时间回看。
