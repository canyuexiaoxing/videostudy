# 字幕位置与样式设置

在播放器上方字幕版本旁提供“字幕设置”按钮，展开面板调整垂直位置（5–90%，顶部/居中/底部预设）、字号（16–48 px）、文字颜色与不透明度、背景颜色与不透明度、加粗和文字阴影，支持恢复默认。原文、AI 校正及翻译字幕共用外观设置，保存到当前浏览器的 localStorage，不修改视频文件、字幕文字或时间。

继续使用 HTML video 原生 WebVTT 轨道。通过 VTTCue 百分比位置及动态 ::cue 样式实现；暂停时更新位置需要对当前活动 cue 移除后重新加入，以刷新 Chromium 缓存的布局。切换课程、字幕版本和重新加载轨道时重新应用位置。存储数据校验颜色、数值范围，失败回退默认。字幕字号使用 px，全屏沿用用户设置。

验证：15 项相关前端测试通过，生产构建通过；真实课程在 Chrome 中将字幕从默认底部移动至 20%、字号改为 32 px、文字改为黄色、背景不透明度改为 30%，截图确认暂停时立即生效。刷新后保留设置，没有浏览器运行异常。视频自带文字不会随这些设置改变。
