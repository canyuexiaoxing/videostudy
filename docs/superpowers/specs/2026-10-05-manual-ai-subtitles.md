# AI 字幕按需生成

## 需求

课程默认展示原文字幕。AI 校正与中英翻译由用户点击生成按钮触发，不能在上传、读取历史或切换语言时自动生成。页面理解完成后才使用课程材料生成字幕，不重新 OCR，也不要求再次上传视频。

## 设计

- 前端上传明确发送 `aiSubtitles=false`；删除高级选项中的自动生成开关。
- 上传接口的 `aiSubtitles` 缺省值改为 `false`。保留明确传入 `true` 的旧接口兼容路径，其来源发布移至页面理解完成之后。
- 播放器字幕区域提供 AI 目标语言及「生成 AI 字幕」。课程主分析未完成、生成请求提交中或该语言正在生成时禁用重复提交。
- 生成按钮调用现有字幕独立任务接口，读取保存的原始语音及页面组 OCR；主分析不依赖该任务。默认仍播放原文，已有结果可切换使用。
- 读取历史和切换目标语言仅查询状态。未生成的语言显示生成入口；已有结果复用，旧版本的更新仍需点击。
- 已有当前版本字幕显示「重新生成 AI 字幕」，显式发送 `force=true` 重置已完成或部分完成的字幕缓存。普通请求仍复用缓存；排队或生成中的任务不会被重置，按钮同时禁用。

## 验证

- Java 上传接口测试：不传字幕选项时成功接收视频，但不创建字幕生成任务。
- Python 流程测试：未传字幕回调令牌时不发布生成材料；显式开启的兼容请求仅在页面理解完成后发布。
- 运行前端字幕测试和生产构建，确认语言选项在尚无 AI 字幕时可用。

本需求替代早期设计中的「上传默认自动生成」行为；不改变校正提示词、模型模式或已缓存字幕。
