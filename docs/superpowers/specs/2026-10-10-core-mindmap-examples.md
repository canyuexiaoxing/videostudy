# 核心知识导图与例题时间节点

用户确认：导图保留核心内容、公式，围绕知识体系、核心概念、知识点关系、原理与流程、对比与区分、重点与易错点组织。具体例题独立放时间节点，不将题号、具体数据代入、计算步骤和答案作为导图分支。例题中提炼出的通用公式和方法仍保留核心知识。

## 实现

- Python 同一次导图请求输出 children 与 examples，不增加模型请求次数。新提示版本 grounded-mind-map-v3-core-examples；仅导图缓存输入加 contentPolicy，媒体和页面缓存上下文仍沿用 v2，避免无关重算。
- 例题时间取已验证转写 sourceIds 的最早开始、最晚结束，忽略模型提供的时间。缺失引用的例题不展示，重叠完全相同的区间去重。
- 显式 kind=knowledge 优先于标题例题启发式；没有可靠核心引用时仍保留独立可靠例题。只有例题时核心状态 empty。
- Java 校验例题引用、起止时间和叶子结构，兼容旧记录缺少 examples。刷新允许有效 empty + examples 结果替换旧版例题导图；失败或空白刷新保留此前有效结果。
- 前端导图下方展示例题时间节点。点击直接回看，不选择导图知识点，不改变 AI 练习范围；仅例题课程仍显示时间节点。
- 已有导图不会自动触发模型调用，需点击“重新生成导图”应用新规则。

## 验证

Python 182 项（181 通过，1 跳过），Java 82 项，前端 37 项，Vue 类型检查及生产构建通过。浏览器使用本地短视频与模拟响应验证独立时间节点、真实回看、练习范围不变、移动端无溢出。没有调用付费模型，不代表语义质量已完成实测。前端主包超过 500 KB 的既有构建警告仍存在。
