# 放射状思维导图与浅色界面修订

用户反馈：现有纵向树更像目录，参考图是白底、多色细曲线、向两侧展开的思维导图；生成层级不应固定为三级，整体界面应干净明亮，不采用原有的灰绿暗色。

## 行为

- 使用项目内安装的开源 SVG 思维导图库渲染 `mindMap` 现有树形数据，布局为真正的 `mindMap`。节点沿曲线连接，分支有区分色；画布可拖动、缩放、适应窗口和展开/收起。课程视频和证据引用仍由本项目负责，图库只负责布局与交互。
- 节点点击通过稳定的 `uid` 找回原始 `MindMapNode`，沿用现有 `jumpToMindMapNode` 跳转本地播放器，并显示转写原文。折叠操作与跳转分开，避免点知识点时仅发生折叠。
- 思维导图从结果栏移到全宽区域，解决深层分支被窄栏压缩。无导图、失败、旧任务和无本地视频时保留现有提示。
- 全站改用明亮的纸白/淡紫背景与深色正文。彩色只用于分支线和少量按钮强调；普通正文、输入框、PPT 证据、状态和焦点态均要可读。
- Python Agent 的新结构允许任意必要的子层级。每个叶子节点必须引用真实转写片段；上层节点可从有效子节点继承引用。单次输出限制总节点数量以防超大响应，不设置产品层级上限。Java 校验移除固定深度限制，保留总节点数与引用真实性检查。旧三级结果兼容。

## 验收

1. 同一份历史任务在宽画布显示为双侧曲线导图，节点可点击跳转相同的本地时间；旧结果无须迁移。
2. 至少五层的合法模型输出能保存、渲染、跳转；无证据虚构节点被拒绝。整棵树仍有总量保护。
3. 画布能平移、缩放、适应窗口；窄屏可操作。浅色界面无旧灰绿暗色块。
4. Python、Java、前端测试和真实浏览器点击测试通过；页面截图人工检查。
