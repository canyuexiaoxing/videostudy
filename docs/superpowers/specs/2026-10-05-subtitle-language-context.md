# 无 OCR 时的语言上下文校正

用户要求：无 OCR 依据时，也应结合常识、近似读音及讲解语境判断明显识别错误；证据确实不足时保留原文。每个分块一次决策，不增加语义复核。

提示词明确 OCR 不是必要条件。可以凭常用词、句意、相邻讲解和相似发音纠错，如试题语境中的“心题 → 新题”。截图“例3”可以辅助判定“例三”，但不能把任何“第三个”都自动改成“例三”。不因某个词不常见就一律替换，不凭常识添加数字、姓名、事实或未说出的整句。

无 OCR 修改使用空 evidence 数组，在 reason 写明语言及上下文依据；使用 OCR 时仍引用实际提供的文字和时间。存在多个合理解释时保留原文。模型没有听原音，这仍是文字推断。

版本：`subtitle-calibration-v6-language-context`，Java 与前端旧缓存识别同步更新。原文与时间不变。
