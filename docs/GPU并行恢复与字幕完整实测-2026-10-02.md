## 显存与质量限制

每 500ms 采样整张显卡：分析前 1042 MiB，峰值 3099 MiB，增量约 **2057 MiB（2.01 GiB）**。这是整张显卡含桌面、浏览器的采样，增量只近似反映本次分析增加的占用，可能漏掉瞬间峰值。

单独 3 张真实截图 GPU 检查，Paddle 分配器报告已分配峰值 677.7 MiB、保留峰值 1439.6 MiB。分配器值不包含全部 CUDA 上下文等占用，不能替代整卡采样。首次模型加载及识别 4.683 秒，后两张分别 0.521 与 0.363 秒。

CPU 与 GPU 识别并非逐字一致：第一张 GPU 未读出 CPU 曾识别的 `192-160=32`、`①②` 批注；其他两张存在字母、空格差异。未减少模型、截图分辨率或证据规则，也不宣称 GPU 输出与 CPU 完全相同。后续扩大样本时需要继续检查数字、算式与手写内容。

OCR 模型跨任务常驻，任务完成后仍会保留模型及部分显存缓存。删除临时视频只清理媒体，不能据此推断模型显存已全部释放。
