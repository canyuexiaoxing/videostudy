# VideoStudy 开发环境与技术栈（选型草案）

> 日期：2026-09-26。本文补足构建工具与运行环境；**仓库目前只有文档，尚未创建这些项目或验证版本组合**。依赖的精确补丁版本要在首次联调后写入锁文件、pom.xml 和镜像标签。架构以“Electron + Vue 桌面端，Java/MySQL/Python 服务器分析”为准。

## 1. 一眼看懂

| 层 | 选型 | 构建/运行位置 | 作用 |
| --- | --- | --- | --- |
| 桌面窗口 | Electron | 用户电脑 | 选择和播放本地视频、文件关联、桌面安装包 |
| 前端 | Vue 3 + TypeScript + Vite + Vue Router + Pinia | 用户电脑 | 课程、导图、转写、答题、诊断界面 |
| 前端构建 | Node.js 24 LTS + npm | 开发机/CI | 安装依赖、构建 Vue 与 Electron |
| Java 后端 | JDK 21 + Spring Boot 3.5.x | 服务器 | HTTPS API、上传、用户、任务、业务校验、持久化 |
| Java 构建 | Maven 3.9.x | 开发机/CI | 编译、测试、打可执行 JAR |
| 数据访问 | MyBatis + MySQL Connector/J + Flyway | 服务器 | SQL 映射、数据库连接与表结构迁移 |
| 数据库 | MySQL 8.4 LTS | 服务器 | 用户、课程、任务、转写、证据、知识图和学习记录 |
| Python 服务 | Python 3.11 + FastAPI + Pydantic | 服务器 | 视频分析接口、Agent 流程、结构化结果 |
| 视频处理 | FFmpeg + OpenCV/Pillow | Python 容器 | 音轨提取、采样、画面粗选与补采 |
| 语音转写 | faster-whisper，模型型号待测 | Python 容器 | 带时间的语音转写 |
| PPT 文字 | PaddleOCR，模型型号待测 | Python 容器 | 对候选截图 OCR |
| Agent 编排 | 普通 Python 函数；诊断分支使用 LangGraph | Python 容器 | 错因判断、检索、核验、澄清和追问 |
| 文本模型服务 | DeepSeek API，具体模型 ID 待联调 | 第三方云端 | 知识抽取、错因诊断、证据复核、追问生成 |
| 部署 | Docker Engine + Docker Compose，HTTPS 反向代理 | 服务器 | 编排 MySQL、Java、Python 与存储卷；无需模型服务容器 |

**MySQL、Java、Python、FFmpeg、ASR 和 OCR 运行在服务器；文本大模型由 DeepSeek API 提供，无需本地部署。**用户只安装 Electron 桌面软件。Node.js、Maven、JDK 和 Python 是开发/构建环境；打好的桌面安装包不要求用户另外安装它们。

## 2. 前端与桌面端

- **Vue 3 + TypeScript + Vite**：页面组件和构建工具。Vue Router 管课程、播放器、学习记录页面；Pinia 管当前课程、视频位置、上传/分析状态。
- **播放器**：HTML video/audio 元素。Electron 提供受控的本地媒体访问，前端点击导图证据时设置播放器 `currentTime = startMs / 1000`，并同步滚动转写稿。字幕由网页叠加，不修改原视频。
- **导图/关系图**：首版选 Vue Flow 或同类可编辑节点组件，底层数据由服务器返回 `Concept / Relation / EvidenceRef`，点击节点、连线展示原句和视频时间。组件只负责绘图，证据与关系逻辑由团队实现。
- **上传**：Electron 获取用户选择文件的受控句柄；按块经 HTTPS 上传给 Java，提供暂停、继续、取消、失败重试和上传进度。上传期间播放器仍使用本地原文件。
- **文件关联**：客户端保存 `mediaId → 本地文件` 的映射；下次打开时检查文件是否存在，必要时请用户重新选择。服务器不保存客户端绝对路径。
- **桌面打包**：可用 electron-builder 制作 Windows 安装包；开发期先用 Electron 开发启动命令。Electron 安全设置使用 context isolation，renderer 不启用任意 Node API。
- **前端依赖**：使用 npm lockfile 固定版本。初版不同时引入多个 UI 组件库和多个状态管理框架。

## 3. Java 后端与 Maven

建议一个 Maven 项目 `backend-java/pom.xml`，采用 JDK 21、Spring Boot 3.5.x。主要依赖：Spring Web、Validation、Security、Actuator、MyBatis Spring Boot Starter、MySQL Connector/J、Flyway、Spring Boot Test。具体兼容版本由 Maven 构建和启动验证后固定；Spring Boot 3.5 官方支持 Java 17+ 与 Maven 3.6.3+，所以 JDK 21/Maven 3.9.x 在其支持范围内。[Spring Boot 系统要求](https://docs.spring.io/spring-boot/3.5/system-requirements.html)

Java 模块建议：

| 模块 | 负责内容 |
| --- | --- |
| auth | 用户登录和课程访问权限；明确桌面端如何保存与刷新凭据 |
| media | 课程元数据、本地文件指纹、课程删除与重新关联校验 |
| upload | 分片上传会话、字节校验、合并、取消、配额与过期清理 |
| job | MySQL 任务记录、状态机、租约/心跳、并发上限、重试 |
| agent-client | 调用服务器内 Python API；校验超时、错误码和结构化结果 |
| knowledge | 转写、OCR、概念、关系、证据的查询与写入 |
| learning | 练习、回答、错因诊断、追问、掌握状态与错因笔记 |

MyBatis 映射由团队写 SQL，适合明确控制“按课程和时间段查询片段/证据”的查询。Flyway 用 `V1__init.sql` 等迁移脚本管理表结构，不用手动在不同开发机上改数据库。Java 是唯一写业务数据的服务；Python 不直接访问 MySQL。

开发命令在 Maven 项目创建后通常是 `mvn test`、`mvn package`、`java -jar target/…jar`；最终命令以实际 pom.xml 和产物名为准。

## 4. Python Agent 与模型

建议 `agent-python/pyproject.toml` 或锁定的 requirements 文件，选 Python 3.11。主要包：FastAPI、Pydantic、HTTPX、faster-whisper、PaddleOCR、OpenCV/Pillow；LangGraph 只用于需要分支与工具回退的诊断流程。Python 通过服务器端密钥调用 DeepSeek API；设请求超时、限流、重试和用量日志。OCR/ASR 的 GPU 依赖要按服务器驱动和镜像实测，不能仅凭依赖列表保证可运行。

处理流程：

1. FFmpeg 从临时视频提取音轨；faster-whisper 输出带起止毫秒的转写段。
2. FFmpeg 约每 2 秒粗采样，OpenCV 对缩小后的画面计算差异；筛出候选后局部以 0.5 秒补采。仅对代表帧用 PaddleOCR。
3. 对齐转写与 OCR 时间，分段向 DeepSeek API 发送相关文本提取概念和关系；每条关系引用真实片段 ID。程序先核验 ID、时间和原文，再核验语义支持。
4. 诊断 Agent 输入题目、学生回答、有限错因类别及课程证据，输出错因、学生原话、证据、推荐视频区间和追问。证据不足则澄清，不编造老师讲过的话。
5. Python 返回 JSON；Java 做第二次 schema 与引用校验并写 MySQL。

**LangGraph 不是模型，也不是视频处理器。**基础流水线用普通函数；错因诊断出现“澄清、再次检索、证据不足、局部重试”等分支时，用 LangGraph 管状态与转移。LangChain 可用于模型适配，但不是首版必装依赖。文本生成统一由 Python 调用 DeepSeek API。API Key 只放服务器机密配置，不能进入 Electron、Git 仓库或日志。DeepSeek 的 JSON 输出仍须由 Pydantic 和 Java 校验，不能把合法 JSON 等同于正确证据。[DeepSeek JSON 输出文档](https://api-docs.deepseek.com/guides/json_mode/)

## 5. MySQL、临时文件与服务器部署

Docker Compose 初步管理三个服务：`mysql`、`java-api`、`python-worker`；HTTPS 入口可由现有反向代理承担。对外只暴露 HTTPS，MySQL 和 Python 接口只在内部网络可达；仅 Python 服务可使用服务器端 DeepSeek API Key。数据库密码和其他凭据用服务器的机密配置，不提交到仓库。

存储分三类：

| 存储 | 内容 | 规则 |
| --- | --- | --- |
| MySQL 持久卷 | 用户、课程、转写、图、证据、回答、任务 | 容器重建不能删除；备份与迁移 |
| 共享临时目录 | 上传分片、合并视频、音频、候选截图 | Java 与 Python 都能访问；成功后删，失败/取消按期限清理 |
| 模型目录 | ASR、OCR 模型文件 | 按许可证获取与保存；镜像重建时复用；不保存 DeepSeek 文本模型权重 |

若 ASR/OCR 使用 GPU，先在服务器验证驱动和 Docker GPU 支持，再给 Python 容器分配 GPU；并将重分析任务并发限制在设备可承受范围。[Docker Compose GPU 指南](https://docs.docker.com/compose/how-tos/gpu-support/)

## 6. 开发机最少需要什么

- **前端成员**：Node.js 24 LTS、npm、Git；本机可运行 Electron。联调前可用模拟 Java API。
- **Java 成员**：JDK 21、Maven 3.9.x、Git；可连接测试 MySQL。用 Docker Compose 启动数据库通常比每人手工安装更容易保持一致。
- **Python 成员**：Python 3.11、FFmpeg、Git；根据模型选择 CPU 或 GPU 环境。先用短视频样本验证依赖。
- **集成/部署**：一台 Linux 服务器，Docker Engine 与 Compose，HTTPS 域名/入口，足够的上传临时空间和模型存储；若需 GPU，提前验证容器可识别它。

用户电脑无需 MySQL、Java、Python、Docker、FFmpeg 或 AI 模型。首次打开桌面软件只需连接服务器、登录并选择本地课程视频。
