# 出题 JSON / LaTeX 格式修复（2026-10-19）

## 修改范围

只改出题回复的读取、格式纠错与错误提示，不改导图生成、粗选、同页分组或既有证据/答案/算式/图结构校验。三种出题材料模式（原导图会话、相关资料、原有文字模式）共用这条回复处理路径。

1. 本地处理能明确判定的数学转义：`\(...\)`、`\[...\]`、`$...$`、`$$...$$` 内的非法单反斜杠，以及 `\frac`、`\theta`、`\begin` 等与合法 JSON 控制转义重叠的常见命令。不全局替换反斜杠，保留合法换行、制表符、引号、Unicode、矩阵换行和路径。不明确的输入不猜测修复。
2. 仍有 JSON 语法或必需字段缺失等格式问题，保留原会话材料、图片、历史和原回复，最多追加一次格式纠错。一次列出能够识别的所有问题。不改变已有题干、数字、答案、选项顺序、证据和图数据；检查纠错回复是否保留已有内容，不能核实或改动内容则拒收。
3. 纠错后仍走原来的逐题校验。答案、证据、算式、图结构错误仍剔除，不因这些语义错误自动再调用模型。只有字段缺失、且原批次仍可读取时，纠错失败也会继续逐题检查原批次，保留其中合格的原题；整份不可读取的 JSON 则明确失败。
4. 一次纠错耗尽后返回 `practice_format_repair_failed`；Java 不再把它当临时服务故障排队重试。界面说明已尝试一次格式修复。原有首次网络/限流错误的处理保留。
5. 诊断日志记录课程、每次请求编号、阶段、问题数、用量、耗时及结果。日志不包含完整回复、课程材料、密钥或图片 base64。合法数值检查额外拒绝 NaN/Infinity/浮点溢出；重复 JSON 键不静默覆盖。

| 场景 | 请求题数 | 通过校验并保存 | 剔除 | 接口耗时 |

| 函数带图出题 | 3 | 3 | 0 | 4.36 秒 |

四次模型本身均返回合法 JSON，未触发额外格式纠错调用。不能把本轮成功全部归因于修复；坏格式本地恢复、保留原会话纠错和一次预算由模拟故障回归验证。共保存 8 题，仍有不合格题被原校验剔除。本次新结构图的真实样本仅几何，其他结构图类型主要由离线回归覆盖。不能据此保证任意课程都会配图或全部出题成功。
