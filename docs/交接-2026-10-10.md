## 最近讨论：怎样基于 base 做深入创新

以下是建议，未实现、未最终选定。

研究主张：资源有限时提升课程语音识别质量，而不是宣称 base 超过所有大模型。

1. **动态页面术语提示**：从当前页面提取可靠术语，只给相应音频段提示，减少整课无关术语干扰。不改权重，重点研究上下文如何选取与对齐。需考虑 OCR/页面理解晚于首次 ASR 的依赖，不能承诺无需额外处理即可用于首次识别。
2. **只重识别可疑片段**：利用识别分数、重复异常、上下文与课件不一致等信号，选择少量短音频再识别；预算和停止条件明确，不重跑整课。低分不一定错，高分也可能错。
3. **领域微调 base**：需要人工准确的音频—字幕配对，学习教学术语与口音；改权重。faster-whisper 是推理工具，训练要另用工具链再转换。不能拿未经校验的 LLM 字幕直接当训练真值。

推荐的先行实验：原始 base、仅动态提示、仅重识别、二者结合四组；使用同一人工标注评测集，测 CER、术语/数字错误、误改率、耗时、内存。更强模型作参考。训练与测试按课程/讲者隔离，避免数据泄漏。

单纯加提示词或调参通常是工程优化；提出可靠的选择与决策方法、对比既有研究并做消融实验，才可能形成研究贡献，原创性仍需检索确认。

另外讨论过的创新方向：
- 保留推导过程的关键帧选择：区分换页、增加、擦除、替换与光标移动；不能只保留最后一张，否则会丢失被擦掉的步骤或纠错过程。
- 有成本预算的补采：语音已足够时不补，缺少关键画面时选少量时间点并停止。此前大量补采问题已有改动，改前先看实现，不能重建旧逻辑。

- FireRedASR 官方旧版表：中文四数据集平均 CER：LLM 3.05%、AED 3.18%、Seed-ASR 3.33%、SenseVoice-L 4.47%、Paraformer-Large 4.56%、Qwen-Audio 6.19%、Whisper-Large-v3 9.86%。这是开发团队表，不是独立通用排名；不包含当前 base，也不是当前所有新版本的排行。
- Seed-ASR 没查到官方可下载权重；SenseVoice-L 未查到公开权重，可下载的是 Small。不得把 L 的成绩套到 Small。

- 先前对 GPU 配置的数字多数是试验建议：FireRed LLM/Qwen-Audio 24GB 起步、AED 8～12GB、Paraformer 可 CPU 或 4～8GB 卡试验；不是官方最低门槛、不是实测占用。
