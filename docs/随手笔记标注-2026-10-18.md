# 随手笔记：图文与画面标注

- 在随手笔记中选择“标注当前画面”，视频暂停并截取当前真实视频帧，保留时间点。
- 提供画笔、荧光笔、箭头、矩形、椭圆、橡皮；颜色、粗细、实线/虚线可选，支持撤销、重做、清空。
- 橡皮只擦标注层，保留原图。按“使用这张图片”回到笔记，再按“保存笔记”。
- 可保存纯文字、纯图片、图片加文字，也可添加本地 PNG/JPG/WebP 图片（12 MB以内）。
- 已保存笔记可编辑；保留原图及标注轨迹，可以继续编辑先前的笔画。点击图片放大查看，点击时间回放。
- 笔记和图片存于客户端 IndexedDB，不上传图片；原有 localStorage 文字笔记事务迁移，成功后才移除旧副本。迁移标记防止已删笔记被重新导入。
- 画布最长边为2560像素；标注图片保存PNG。原图/轨迹及合成图一并保存。
- 保存失败时草稿保留；图片与视频时间绑定，不随之后播放位置改变。不同视频的草稿与已保存笔记分开。
- 编辑器关闭前的笔画仅在编辑器内；点“使用这张图片”进入当前会话草稿，点“保存笔记”后才持久保存。
- 原始视频无可解码画面、正在跳转或跨域视频不允许读取时不能截图；可添加本地图片，不触发AI调用。

验证：浏览器实际绘制、擦除像素回到原图、撤销重做、各类形状、图片/图文保存、刷新恢复、旧笔记迁移、编辑、存储失败保留草稿、视频隔离及窄屏布局。
