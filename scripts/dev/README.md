# 开发辅助脚本

本目录存放开发、验证、浏览器检查与本地部署辅助脚本。

## 存放约定

- 后续辅助脚本放在 `scripts/dev/`，按用途建立子目录，例如 `qa/`、`deploy/`。
- 脚本以自身位置推导项目根目录；不要写死开发者的盘符或 Codex 临时目录。
- 截图、日志、临时数据、打包镜像上下文放在项目 `.local/qa/` 或 `.local/dev/`；这些路径已被 Git 忽略。
- 正式测试继续保留在各模块的测试目录，不移到这里。
- 不在脚本中保存密钥或私有数据。

## 历史归档

`archive/2026-10-11/` 保存本次开发生成的历史脚本，包含截图中提到的 `analysis-area-tests.py`、`analysis-area-python.py`、`analysis-area-java.py` 等。`manifest.json` 记录 SHA-256，可核对归档完整性。

历史文件保留原始内容，仅用于追溯。部分脚本执行一次性文本替换、追加测试或重启服务，也保留了旧的绝对路径与环境依赖；**不要直接批量执行，也不要默认可重复运行**。需要复用时，先检查代码版本、路径和副作用，再整理为本目录下可复用的脚本。

原临时目录副本暂时保留，避免影响已有文件链接。后续脚本不再写入该目录。
