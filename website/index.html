A FEW THINGS TO KNOW

开始前，
你可能想知道。

把疑问放下，再安心开始。

视频需要上传到云端吗？
本地分析模式下，原视频由本机处理，不需要把整个视频上传到云端。AI 解读、导图和问答会将所需的课程文字，以及适用时的课件图片，发送给你配置的模型服务。因此，本地优先不代表所有功能完全离线。
使用软件需要付费吗？
当前版本的安装器可直接下载。AI 功能需要你自己的 DeepSeek API 密钥，调用费用按模型服务商的规则从你的账户扣除，具体费用以服务商为准。官网不会收集你的 API 密钥。
为什么安装器只有 41 KB？
这是一个在线安装入口。运行后会从下载源自动获取约 6.29 GB 的压缩组件，展开后的程序和环境约为 10.83 GB。安装期间缓存与程序同时占用空间，建议预留至少 19 GB；安装成功后默认清理下载缓存。
下载中断，需要从头再来吗？
安装器支持暂停、继续和断点续传。下载未完成时，关闭后再次打开同一版本安装器，会尝试复用已下载文件。每个组件都会校验完整性，校验失败的文件不会用于安装。
没有独立显卡，可以运行吗？
软件会检测本机的运行环境，优先使用可用且兼容的 GPU，也支持 CPU 模式。没有兼容显卡时，视频转写和画面识别可能耗时更长。实际速度取决于硬件、视频长度和所选分析选项，暂不承诺固定处理时长。
课程记录和笔记保存在哪里？
桌面版将课程历史、分析结果和笔记保存在本机用户数据目录，可在软件“设置 → 数据与维护”中打开目录或导出备份。原视频需自行保管，备份不包含原视频、API 密钥或已下载模型。
